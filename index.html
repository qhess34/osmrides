⚡ Tonnerre 2 Zeus — à vous les commandes

Vous êtes chef d'attraction des montagnes russes en bois de Zeus. Faites tourner les trains, gardez les visiteurs heureux et l'attraction en bon état.

  • Ouvrez l'attraction pour laisser entrer les visiteurs dans la file. Ils se rangent sur le quai, deux par travée, derrière les portillons.
  • Mode auto : les portillons s'ouvrent dès que le train est vide et il part une fois plein. Mode manuel : ouvrez les portillons vous-même, puis cliquez sur « Départ ! » (ils se referment avant le départ).
  • Trains : sortez le second train du garage pour doubler le débit, renvoyez un train au garage pour le réviser.
  • Maintenance : l'usure augmente à chaque tour. Plus elle est haute, plus les pannes sont fréquentes (lift bloqué, freins, harnais). À 100 %, l'élément est hors service.
  • Orage : quand Zeus se fâche, suspendez les départs (mode manuel ou arrêt d'urgence). Chaque train envoyé sous l'orage coûte une amende.
  • Les visiteurs qui attendent trop longtemps repartent mécontents. Le parc ferme à 18:00.
  • File modulable : deux raccourcis (est et ouest) court-circuitent une boucle de la file. Cliquez sur une barrière de la file, ou utilisez les boutons : les barrières pivotent et les visiteurs suivent le chemin ouvert. Raccourci ouvert : file courte. Raccourci fermé : file longue, plus de capacité.
  • Vue aérienne : glissez pour vous déplacer, molette pour zoomer jusqu'aux visiteurs, ou suivez un train avec les boutons en bas de la vue.

Chaque passager rapporte 5 €. Les salaires coûtent 350 € par jour.
