## Synchronisation vers OSM (issue #46, D12)

- Lecture : `OSM.attrs` (`docs/ref/fichiers.md`) donne la valeur par défaut de `GAME.look` : `engine/render.js` `OSML` (valeur dominante par longueur) ; priorité `GAME` > OSM > `SITE` > défaut ; correspondances surface : concrete, asphalt, compacted | fine_gravel = sand, paving_stones | sett = pavers, wood = deck ; `material` des garde-corps (metal | steel | iron, wood, stone | brick | concrete, `barrier=wall` = pierre) ; béton OSM d'une allée = origine du moteur (`TEX.stone`) ; `colour` de la voie = `SITE.track.spine` (`engine/core.js`, coaster inversé ou acier).
- `GAME.look.roof` (`#rrggbb`) : couleur du toit de la gare, priorité `GAME` > `roof:colour` du bâtiment (`OSM.attrs` rôle `roof`) > `SITE.stationRoofCol` > couleur du bâtiment ; `engine/render.js` `drawBld`, `look()`.
- Éditeur : chaque réglage de la section « Apparence » porte « OSM » (valeur lue dans OSM, `GAME` absent ou identique) ou « modifié » (écart) ; « Origine » revient à la valeur OSM ; les portillons n'ont pas d'équivalent OSM.
- Écarts : `editor/schema.js` `osmDiff(game, attrs, {plats})` (modify : `{type, role, id, v, key, from, to}` ; create : polygone de sol du quai `area:highway=footway`, `covered=yes`, `level=0`, `surface`, `colour`, depuis le quai calculé, seulement sans polygone dans OSM, décoché par défaut) ; clés envoyables `OSM_TAGS` : `surface`, `colour` (file, quai, voie), `material` (garde-corps), `roof:colour` (bâtiment de la gare) ; le sol du quai est un polygone à part sous le toit, jamais `surface` sur le bâtiment.
- Envoi : `editor/osm-sync.js` (via `editor/server.js` : `GET /osm/login`, `/osm/callback`, `GET /api/osm/status`, `POST /api/osm/send/<site>`) ; OAuth2 PKCE S256, scope `write_api`, jeton en mémoire seulement ; configuration `editor/osm.local.json` (`clientId`, `api`, `auth`, `web`, ignoré par git et jamais servi, modèle `osm.local.example.json`, variable `OSM_CONFIG`) ; liste blanche des clés et valeurs ; relecture fraîche de chaque objet, refus 409 si la version a changé depuis l'import ; changeset `created_by=OSMrides editor` + `comment`, osmChange (modify : tags existants et nds gardés ; create : ids négatifs, polygone fermé, coordonnées depuis `origin` de `tools/specs/<site>.json`), fermeture ; bouton « Envoyer vers OSM » (`#bOsm`, panneau `#modalOsm`), procédure du compte dans `editor/README.md`.
